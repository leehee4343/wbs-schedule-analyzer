WBS 파일 업로드

매주 작성하는 상세일정계획 WBS 엑셀을 그대로 올려 주세요.

"WBS(계획)"·"WBS(실적)" 시트의 단계 · 활동 · TASK · 가중치 · 진척율 · 계획 시작/완료 · 실제 완료 값을 읽어 대시보드, 금주·차주 업무, 지연 업무, 공정율을 다시 계산합니다.

파일명 앞 8자리(YYYYMMDD)가 기준일이 되며, 최종 저장을 누르면 분석 결과가 클라우드와 이 브라우저에 보관됩니다.

WBS 엑셀 파일을 선택하거나 이 영역에 끌어다 놓으세요 상세일정계획_WBS_*.xlsx (.xlsx, .xls)
분석 결과를 최종 저장합니다. 분석 결과를 확인한 후 최종 저장하면 분석 결과 조회 메뉴에서 다시 불러올 수 있습니다.

EmailJS 발송 설정

미설정 — 메일 앱으로 대체 발송

GitHub Pages 배포 시에는 저장소의 config/emailjs.config.js에 값을 입력하면 모든 사용자가 같은 설정으로 메일을 발송할 수 있습니다.

  1. emailjs.com에 가입합니다(월 200건 무료).
  2. Email Services 탭에서 Add New Service를 눌러 Naver 또는 Gmail을 SMTP로 연결합니다.
  3. Email Templates 탭에서 템플릿을 만들고 To {{to_email}} · CC {{cc_email}} · Subject {{subject}} · Body {{message}} · Reply-to {{reply_to}} 변수를 연결합니다. 서식 포함 본문은 Body에 {{{message_html}}}를 사용합니다.
  4. Account → API Keys에서 Public Key를 복사합니다.
  5. 배포용 설정 파일을 채우기 전에는 아래 값을 입력하고 이 브라우저에 저장합니다. 발신 표시명과 회신 이메일은 선택 항목입니다.
